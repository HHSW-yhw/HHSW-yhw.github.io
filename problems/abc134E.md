## 题意

<!-- 用自己的话把题目要求说一遍：给了什么、要你算什么、数据范围多大 -->

给定一个长度为n的序列，求这个序列的严格递增的子序列的最少数量，n的范围是1e5。

## 思路

<!-- 从暴力想法开始讲，说清楚为什么会超时，再讲怎么优化 -->

没什么可讲的，就是经典的导弹拦截及其衍生的dilworth定理。接下来会结合代码给出证明，以后不要再忘记了。

### 定理内容

在任意有限偏序集中，最大反链的大小等于覆盖该偏序集所需的最少链数。

### 证明

说人话就是给定一条序列，求最长严格递增子序列的长度就等于求非严格递减的子序列（即反链）的最少数量。那么放到这道题，求这个序列的严格递增的子序列的最少数量就是求非严格递减的最长子序列的长度。

1. 依据从dp演化而来的贪心加二分的求最长子序列的解法就是这样写的：设dp[i]为长度为i的非严格递减子序列的最大值，可得dp[i]是一个非严格递减的序列。从前往后扫描，遇到一个数用二分找到第一个严格小于它的数（注意是严格小于）并替代，如果所有的数都大于等于它，那么增加一位。

```cpp
for (int i = 1; i <= n;i++) {
	if (i==1) {
		dp[1] = a[i];
		len++;
		continue;
	}
	int l = 1, r = len;
	while (l<r) {
		int mid = (l + r) / 2;
		if (dp[mid]<a[i]) {      //遇到严格小于自己的数就改变r，但是要直接取等
			r = mid;
		}
		else {
			l = mid + 1;
		}
	}
	if (dp[l]>=a[i]) {
		len++;
		dp[len] = a[i];
	}
	else {
		dp[l] = a[i];
	}
}
```

2. 我们也可以直接贪心得出这道题。为了让严格递增子序列最少，我们就需要让每条链都尽可能长。设dp[i]为第i条链的最后一个值。策略就是把新扫描到的值放在现有的比自己小但是又是最大的值的后面（因为放了之后结尾值就固定了，根据贪心肯定尽量接在较大的值的后面防止浪费）。而且这个dp也是非严格递减的（手模一下就知道了），所以直接二分找到这个序列里面第一个严格小于当前值的位置，然后替代就好了。

3. 惊奇地发现两种做法的代码一模一样，并且其他类型的链的结论的证明同理，得证！

## 关键 trick：运用定理的时候一定要注意严格和非严格的转换，不要搞混了！

<!-- 这篇文章的重点。把「XXXX」这个思想讲透：挂在哪里、什么时候挂、为什么这样能避免重复计算 -->

注意，反链是指把整个符号倒过来，比如严格递增 < 对应非严格递减 >= 而不是严格递减。同理严格递减 > 对应非严格递增 <=。

## 代码

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <unordered_map>
#include <stack>
#include <iomanip>
#include <queue>
using namespace std;
typedef long long LL;
const LL N = 2e5 + 10, MOD = 1e9 + 7;
int n, len, a[N], dp[N];
void solve() {
	cin >> n;
	for (int i = 1; i <= n;i++) {
		cin >> a[i];
	}
	for (int i = 1; i <= n;i++) {
		if (i==1) {
			dp[1] = a[i];
			len++;
			continue;
		}
		int l = 1, r = len;
		while (l<r) {
			int mid = (l + r) / 2;
			if (dp[mid]<a[i]) {
				r = mid;
			}
			else {
				l = mid + 1;
			}
		}
		if (dp[l]>=a[i]) {
			len++;
			dp[len] = a[i];
		}
		else {
			dp[l] = a[i];
		}
	}
	cout << len << "\n";
}
int main()
{
	ios::sync_with_stdio(0);
	cin.tie(0), cout.tie(0);
	int t = 1;
	//cin >> t;
	while (t--) {
		solve();
	}
}
```
